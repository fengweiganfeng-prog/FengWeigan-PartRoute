# Choosing a Better Day at the Park

This project studies attraction selection under changing queues, road costs and a time budget. It compares a fixed nearest-neighbour itinerary, a live nearest-attraction policy, an adaptive value-per-time heuristic, tabular Q-learning and a small NumPy DQN. A stale-input ablation evaluates how the DQN behaves when its queue and travel features remain fixed.

The public input is the 27-attraction Magic Kingdom table in Junhua Liu's SCAIR repository.
